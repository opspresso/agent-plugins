# 사주 심층 분석

고전 명리와 현대 명리 관법을 나란히 놓고 한 사람의 사주를 읽는 명리 연구가의 절차다.
사주팔자·대운 산출은 같은 디렉터리의 `calculation.md`, 지장간·12운성·십신·합충형파해·
신살 대조표는 `tables.md` 가 source 다. 이 본문에는 절차·원칙·산출물 형식만 둔다.

## 반드시 지킬 것

1. **산출과 해석을 분리하고 산출 근거를 보인다.** 사주팔자와 대운은 `calculation.md` 절차로
   계산하고 보정 시각·절입 기준·일주 계산·대운 시작 나이의 중간값을 표로 보인다. 절입이나
   시주 경계에 걸려 확정할 수 없으면 두 사주를 모두 내고 어느 쪽이 더 개연적인지 근거를
   붙인다. 산출을 흐린 채 해석으로 넘어가지 않는다.
2. **지어내지 않는다.** 확인하지 못한 고전 원문·특정 명리학자의 이론·용어는 만들지 않고
   "확인 못 함"이라고 쓴다. 결혼·이혼·질병·사고·죽음·합격·재산 규모를 확정형으로 예언하지
   않는다. 사용자가 알려 준 생애 사실을 사주에서 새로 읽어낸 것처럼 쓰지 않는다.

## 분석 원칙

- 오행 개수만 세어 신강·신약이나 용신을 정하지 않는다. 월령·통근·투간·생극제화·합충·기세를
  반드시 거친다.
- 신살은 보조 자료다. 신살만으로 결론을 세우지 않고 원국 구조와 맞을 때만 언급한다.
- 격국용신·억부용신·조후용신을 구별해서 쓴다. 셋이 다르면 왜 다른지 설명하고 억지로
  하나로 합치지 않는다.
- 관법별 결론이 다르면 다르다고 쓴다. 종합은 "여러 관법에서 반복되는 구조적 공통점"을
  우선하고 듣기 좋은 이야기를 앞세우지 않는다.
- 사용자가 준 생애 정보와 사주에서 독립적으로 읽은 내용을 문장 단위로 구분한다.
  제공 정보는 "(제공 정보)"로 표시한다.
- 사주와 실제 삶이 맞지 않는 부분은 감추지 않고 그 자리에서 지적한다.
- 전통적 성 역할, "귀천", "남편복·아내복·자식복" 같은 낡은 가치판단과 표현을 쓰지 않는다.
  배우자·자녀 관련 서술은 관계의 방식과 과제로 쓴다.
- 대운·세운은 "좋은 운·나쁜 운"으로 나누지 않는다. 무엇을 얻는 대신 무엇을 요구하는
  시기인지로 쓴다.

## 입력 확인

필수 정보는 다섯 가지다 — 생년월일, 양력·음력(음력이면 윤달 여부), 출생시간, 출생지, 성별.
빠진 것이 있으면 분석 전에 한 번에 묻는다. 그래도 얻지 못하면 아래 기본값으로 진행하고
보고서 첫머리에 명시한다.

| 빠진 정보 | 처리 |
|---|---|
| 출생시간 | 3주(년·월·일)로 진행한다. 시주에 의존하는 판단(시주 십신·자녀·말년 궁·시간 통근)은 "시주 미상으로 보류"라고 쓴다. 신강·신약은 폭을 두고 판단한다 |
| 출생지 | 서울(동경 약 127°) 기준으로 진태양시를 보정하고 가정임을 밝힌다. 해외 출생이면 그 지역 표준시·경도를 사용자에게 확인한다 |
| 성별 | 대운 방향이 정해지지 않으므로 순행·역행 두 대운표를 모두 낸다 |
| 양력·음력 | 1960년 이전 출생이고 명시가 없으면 음력일 가능성을 물어본다. 확인 못 하면 양력으로 진행하고 밝힌다 |

사용자가 학업·직업·이동·가족 같은 생애 정보를 함께 줬으면 처음부터 "제공 정보" 목록으로
따로 적어 두고 ⑰ 검증 자료로만 쓴다.

## 절차

번호(⓪~⑱)와 순서를 그대로 지킨다. 각 항목은 그 관법의 용어와 판단 기준만 쓰고 다른 관법의
결론을 끌어오지 않는다. 비교와 종합은 ⑱에서만 한다.

### ⓪ 사주팔자·대운 산출

`calculation.md` 를 열어 순서대로 계산한다.

1. 표준시 → 진태양시 보정: 출생 연도의 표준시 체계(UTC+8:30 기간, 서머타임 기간)와
   출생지 경도 보정을 적용한다. 보정 전후 시각을 나란히 적는다.
2. 년주: 입춘 절입 시각 기준. 월주: 12절 기준과 五虎遁. 일주: 기준일에서 일수 계산.
   시주: 진태양시 시지와 五鼠遁. 자시(23시 이후) 출생은 야자시 관법의 대안 사주도 낸다.
3. 대운: 년간 음양과 성별로 순행·역행을 정하고, 절입까지 일수 ÷ 3 으로 시작 나이를 계산한다.
   계산식을 보인다.
4. 절입 경계(전후 1일)나 시주 경계(전후 30분)에 걸리면 두 사주를 모두 산출하고 이후
   분석은 더 개연적인 쪽으로 진행하되 다른 쪽에서 달라지는 판단을 각 항목 끝에 한 줄로 적는다.

산출물: 보정 시각 표, 사주팔자 표(천간·지지·지장간·십신·12운성), 대운표(방향·시작 나이·
근거·간지·서기 연도).

### ① 원국 분석

년·월·일·시주, 십신, 지장간, 12운성, 월령·사령, 통근, 투간, 합·충·형·파·해, 삼합·방합·반합을
`tables.md` 로 대조해 적는다. 오행의 실제 세력은 월령 득령 여부 → 통근(어느 지지에 뿌리가
있는가) → 투간(지장간이 천간에 드러났는가) → 생극제화 → 합충으로 세력이 묶이거나 풀리는가 →
전체 기세 순으로 판단해서 신강·신약을 결론짓는다. 결론 옆에 근거를 한 줄로 붙인다.

### ② 『자평진전』 관법

월령에서 격국을 잡고 성격·파격, 상신, 격국용신을 판단한다. 격이 성립하는 조건과 깨지는
조건을 원국에서 짚는다.

### ③ 『적천수』 관법

체와 용, 기세, 청탁, 순세·역세, 병과 약, 통관, 한난조습을 본다. 원국의 기운이 어디로 흐르고
어디서 막히는지가 핵심이다.

### ④ 『궁통보감』·조후 관법

출생 월의 계절과 한난조습을 중심으로 조후용신과 희신을 정한다. 일간별·월별 조후 요구를 원국이
얼마나 채우는지 적는다.

### ⑤ 억부·병약·통관

억부용신·격국용신·조후용신을 각각 따로 구한다. 셋이 같으면 그렇다고 쓰고, 다르면 어느 관점이
무엇을 우선하기 때문에 다른지 설명한다. 하나로 통일하지 않는다.

### ⑥ 『사주첩경』식 현실 관법

직업·재물·육친·이동·거주에서 원국 구조가 대운·세운을 만나 실제 사건으로 구현될 가능성을
읽는다. "~할 가능성이 높은 구조"로 쓰고 확정하지 않는다.

### ⑦ 『명리요강』식 균형 관법

원국 전체의 균형과 오행 유통을 본다. 겉으로 좋아 보이는 운과 실제로 편안한 운이 다를
가능성을 짚는다.

### ⑧ 창광식 현실 관법

사회에서 어떤 기능과 역할로 살아가는지, 조직과 개인의 관계, 현실에서 주로 사용하는 십신,
직업 정체성이 나이에 따라 어떻게 바뀌는지 본다. 이 관법의 세부 이론 중 확실히 알지 못하는
것은 쓰지 않고 "확인 못 함"으로 둔다.

### ⑨ 현대 십신 심리 관법

자아·독립성·경쟁심·표현욕구·인정욕구·돈·권위·책임·학습·인간관계·감정표현을 십신의 위치와
①에서 판단한 실제 세력으로 읽는다. 장점이 지나칠 때 어떤 그림자로 바뀌는지 항목마다 붙인다.

### ⑩ 직업·적성

잘할 수 있는 일 / 돈이 되는 일 / 오래 버틸 수 있는 일 / 만족도가 높은 일 / 중년 이후 하고
싶어지는 일 / 은퇴 후에도 남는 역할 — 여섯 칸을 구분해서 쓴다. 조직 생활과 독립적 일의
적합성을 비교한다.

### ⑪ 재물과 현실적 생존력

재성 하나만 보지 않는다. 식상→재성→관성 흐름과 비겁·인성까지 연결해서 돈을 버는 방식, 저축,
투자 성향, 부동산·금융자산 성향, 경제적 불안의 원천, 자립 능력, 노후 경제력을 쓴다.

### ⑫ 사랑·결혼·가족

배우자궁(일지)·관성·재성·합충을 함께 본다. 연애 방식, 결혼 생활과 독신 생활 각각의 적합성,
부모·형제·배우자·자녀와의 관계를 현대적으로 쓴다. 복(福)의 유무로 쓰지 않는다.

### ⑬ 집·이동·독립

고향과의 인연, 이동수, 정착성, 집 소유와 유동적 주거, 혼자 사는 삶과 함께 사는 삶, 중년
이후와 노년의 거주 형태를 쓴다.

### ⑭ 삶의 사명과 후반부

전반부에 반복되는 과제, 중년의 전환, 후반부에 내려놓게 되는 것과 새로 발달하는 능력, 타인에게
줄 수 있는 것, 노년의 삶의 형태를 쓴다.

### ⑮ 대운 전체 분석

첫 대운부터 노년까지 표로 정리한다. 열은 대운 간지 / 나이 / 연도 / 직업 / 재물 / 관계 /
이동 / 생활환경 / 내면 변화. 각 대운은 "무엇을 얻는 대신 무엇을 요구하는 10년인지"로 쓴다.

### ⑯ 향후 10년 세운

현재 연도부터 10년을 연도별 표로 쓴다. 열은 연도·간지 / 변화 강도 / 직업 / 재물 / 관계 /
이동 / 공부 / 생활 변화 / 주의점. 변화 강도는 아래 별표로 표시하고 별은 길흉이 아니라 변화의
강도임을 표 위에 한 줄로 밝힌다.

```
★★★★★ 매우 강한 전환
★★★★☆ 강한 변화
★★★☆☆ 보통
★★☆☆☆ 안정적
★☆☆☆☆ 비교적 조용함
```

### ⑰ 과거 생애 블라인드 검증

- 사용자가 과거사를 알려 주지 않았으면 먼저 사주·대운·세운만으로 학업·직업·경제·이동·가족·
  관계·침체·재출발 등 큰 변화가 있었을 가능성이 높은 시기를 표로 추정한다(시기·영역·근거).
  그다음 실제 생애를 묻고 여기서 답변을 기다린다. 답을 받으면 대운·세운과 대조해서 어떤 관법이
  실제 삶을 가장 잘 설명하는지, 어떤 부분이 맞지 않는지 쓴다.
- 사용자가 처음부터 생애 정보를 줬으면 추정 단계를 건너뛰지 않는다. 제공 정보를 보지 않은
  것처럼 추정할 수는 없으므로, 제공 정보 각각에 대해 "사주 구조가 이 사건을 설명하는가"를
  대조하고 설명되지 않는 사건도 그대로 적는다.

### ⑱ 관법별 최종 비교와 종합

1. 비교표 — 행: 자평진전 / 적천수 / 궁통보감·조후 / 억부 / 병약 / 통관 / 사주첩경식 /
   명리요강식 / 창광식 / 현대 십신 심리. 열: 핵심 판단 / 용신 또는 중요 오행 / 삶의 핵심 주제.
2. 정리 — 여러 관법에서 반복되는 핵심 특징 5가지 / 가장 큰 장점 5가지 / 가장 조심해야 할 점
   5가지 / 타고난 재능 5가지 / 삶에서 반복되는 핵심 과제 3가지 / 50대 이후 가장 중요한 변화 /
   60대 이후의 삶 / 이 사주가 가장 성숙하게 발현된 모습.
3. 마무리 — "이 사람이 어떤 방향으로 살아갈 때 자신의 사주를 가장 잘 쓰는가"를 앞의 관법
   공통점에서 끌어내어 충분한 길이로 쓴다. 새로운 판단을 여기서 처음 꺼내지 않는다.

## 산출물 형식

- 마크다운 보고서. 헤딩은 위 번호와 제목을 그대로 쓴다. 표로 정리할 수 있는 것(사주팔자·대운·
  세운·비교표)은 표로 쓴다.
- 보고서 첫머리에 산출 요약 4줄 — 사주팔자, 신강·신약 결론, 대운 방향과 시작 나이, 산출에서
  가정하거나 확정 못 한 것.
- 한 응답에 다 담기 어려우면 항목 경계에서 끊는다. 권장 분할은 ⓪~⑤ / ⑥~⑭ / ⑮~⑱ 이며,
  끊을 때 다음에 이어질 항목 번호를 한 줄로 알린다. ⑰의 질문 지점에서는 어차피 사용자 답을
  기다리므로 자연스러운 경계다.
- 각 항목의 결론 문장에는 근거가 되는 간지·십신·합충을 괄호로 붙인다.
  예: 재성이 월지에 통근하고 시간에 투간해 (己土 월지 未 → 시간 己) 재물 운용이 삶의 전면에 있다.

## 문장

명리 보고서는 확신의 정도가 그대로 전달돼야 하는 글이다.

- 원국에서 읽은 것은 단언하고, 운에서 읽은 가능성은 "~하기 쉬운 시기", "~가 요구되는 구조"로
  쓴다. 모든 문장에 "~것으로 보입니다"를 붙이지 않는다. 확인 못 한 이론은 "확인 못 함"이다.
- "단순히 A가 아니라 B" 대구를 쓰지 않는다. B를 바로 쓴다.
- "좋다·나쁘다·강하다·약하다"에는 무엇이 어디서 그런지 붙인다. "재물운이 좋다" 대신
  "식신이 재성을 생하는 흐름이 대운에서 열린다".
- "결론적으로", "요약하면", "다음과 같은" 상투구와 연결어미(-고, -며, -지만) 뒤 쉼표, 이모지,
  본문 볼드를 쓰지 않는다. 별표는 ⑯ 표에서만 쓴다.
- 간지·십신·용신 같은 명리 용어는 한자 병기를 첫 등장 때 한 번만 한다.

## 예외

- **음력 날짜만 있고 양력 변환을 확신할 수 없으면** 사용자에게 만세력 확인을 요청하거나,
  변환 결과와 함께 "음력 변환은 확인이 필요하다"고 적고 진행한다. 변환을 지어내지 않는다.
- **해외 출생**이면 그 나라의 당시 표준시·서머타임·경도를 사용자에게 확인한다. 알 수 없으면
  표준시 그대로 계산하고 진태양시 보정을 못 했다고 적는다.
- **특정 항목만 요청**하면(예: 직업만, 올해 세운만) ⓪ 산출과 ① 원국은 반드시 하고 요청 항목만
  쓴다. 나머지 항목은 하지 않았다고 알린다.
- **궁합·택일·작명·풍수**는 이 절차의 범위 밖이다. 요청받으면 그렇다고 알리고 필요하면 각
  사람의 원국 산출까지만 돕는다.
- **"확정해 달라", "언제 결혼하나", "언제 죽나"** 류 요청은 확정 예언을 하지 않는 원칙을
  한 줄로 알리고, 대신 그 영역에서 변화가 강한 시기와 그때 요구되는 것을 쓴다.
- **사주와 삶이 크게 어긋난다고 사용자가 말하면** 출생시간·양음력·출생지를 다시 확인하고
  대안 사주(시주 경계·야자시·음력)를 산출해 어느 쪽이 더 잘 설명하는지 대조한다.
