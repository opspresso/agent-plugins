# 이미지 생성 스킬

사용자가 그림·이미지를 요청하면 **직접 이미지를 생성해서 전달**한다.
새로 그릴지 고칠지부터 정한다.

- **새로 그리기** — `GenerateImage`. 참조할 이미지가 없을 때.
- **고치기** — `EditImage`. 사용자가 올렸거나 이번 대화에서 그린 이미지를
  바꾸거나, 무언가를 더하거나 빼거나, 스타일만 바꿀 때.

절차: ① 무엇을 할지 정하고 → ② 영어 프롬프트로 다듬고 → ③ 툴을 호출하고 →
④ 무엇을 어떻게 했는지 한두 문장으로 설명한다.

## 반드시 지킬 것

- 생성·편집 요청은 해당 툴로 수행한다. 툴이 없으면 제약을 밝히고 프롬프트만 제안할 수 있다.
- 툴 결과 이미지는 사용자에게 자동 전달되므로, "이미지를 보여드릴 수 없다"고
  말하지 않는다.
- **기존 이미지를 바꿔 달라는 요청에 `GenerateImage`를 쓰지 않는다.** 새로
  그리면 원본과 다른 그림이 나온다. 지목할 id가 있으면 `EditImage`다.
- 스타일·비율을 지정하지 않았고 요청이 모호하면, 되묻지 말고 합리적인
  기본값(스타일 1개, 1024x1024, medium)으로 바로 진행한다.

## 이미지 id

시스템 프롬프트의 `## Available Images` 섹션이 이번 런에서 쓸 수 있는 id를
알려준다. `img_1`, `img_2` 형태고, 사용자가 첨부한 이미지와 이번 런에서 그린
이미지가 모두 들어간다. `GenerateImage`도 그린 뒤 새 id를 알려준다.

목록에 없는 id는 지어내지 않는다. URL로 준 원본은 `FetchUrl`이 있으면 먼저 읽고,
이미지 결과와 함께 반환된 실제 `img_N`을 `EditImage`에 사용한다. 웹페이지 텍스트나
URL 자체를 image_id로 넘기지 않는다. 도구가 없거나 이미지를 가져오지 못했을 때 원본
첨부를 요청한다. 대화에 이미지가 여러 개면 요청한 원본과 id를 대조한다.

## 프롬프트 구성 요소

새로 그릴 때는 다음 순서로 구성한다:

1. **주제** — 무엇을 그릴지 한 문장으로 명확하게 (인물, 사물, 장면)
2. **스타일** — photorealistic, watercolor, flat illustration, 3D render, pixel art 등
3. **구도** — close-up, wide shot, bird's eye view, rule of thirds 등
4. **조명과 분위기** — golden hour, soft studio lighting, neon, moody 등
5. **품질 키워드** — highly detailed, sharp focus, 8k 등 (2~3개면 충분하다)

## 편집 프롬프트

편집 프롬프트는 **바뀐 결과 전체**를 묘사한다. 변경점만 적으면 나머지가 무엇이었는지
모델이 모른다.

- 나쁨: `make it night`
- 좋음: `The same street scene at night: shop windows lit from inside, wet
  asphalt reflecting the neon signs, the parked red bicycle unchanged.`

바뀌지 않아야 할 요소를 한 구절로 못 박아 두면 원본이 덜 흔들린다.

## 작성 규칙

- 장면 설명은 영어를 기본으로 하되 이미지에 들어갈 문구와 고유명은 사용자가 준 언어를 유지한다.
- 쉼표로 구분된 구문 나열보다 자연스러운 문장 1~2개 + 스타일 키워드가 좋다.
- 사용자 요청의 구도·내용·유지할 요소를 보존하고 실제 도구가 반환한 제한을 따른다.

## 툴 파라미터

두 툴이 `size`와 `quality`를 공유한다.

- `size`: `1024x1024`(기본) | `1536x1024`(가로) | `1024x1536`(세로)
- `quality`: `low` | `medium`(기본) | `high` — "빠르게"를 원하면 low

| 툴 | 필수 파라미터 |
|---|---|
| `GenerateImage` | `prompt` |
| `EditImage` | `image_id`, `prompt` |

## 답변 형식

- 어떤 장면/스타일로 그렸는지, 편집이면 무엇을 바꿨는지 한두 문장
- 사용자가 요청하면 재사용할 프롬프트를 함께 제공한다

## 실패했을 때

툴 결과가 `Error:`로 시작하면 실패한 것이다. 같은 호출을 그대로 반복하지 말고,
사유를 설명한다. 입력 오류를 바로잡을 수 있을 때만 한 번 다시 시도한다.
이미지 id 오류는 사용자가 지정한 원본이 목록에 있는지 확인해 고친다.
원본을 찾을 수 없으면 다른 이미지로 대체하지 말고 첨부를 요청한다.
