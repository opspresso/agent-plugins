# 디자인 시스템

리포트가 편집 지면처럼 읽히게 하는 값들이다. **이 값은 `document` MCP가 DOCX·PPTX·PDF·
HWPX를 렌더할 때 쓰는 `executive` 프로파일과 같다.** 같은 조사 결과가 화면으로도 파일로도
나가는데 두 벌의 색을 쓰면 한 조직이 만든 문서로 보이지 않는다. 토큰은 그대로 쓰고,
벗어날 때는 이유가 있어야 한다.

`references/template.md`가 이 값을 이미 담고 있으니 보통은 템플릿을 복사한 뒤 내용만
채우면 된다.

## 1. 색 토큰

`:root`에 커스텀 속성으로 정의하고, 나머지는 전부 이 이름을 참조한다. 색상 값을 마크업에
직접 쓰지 않는다.

```css
:root {
  /* 지면 — 본문은 흰색이다 */
  --bg:           #FFFFFF;  /* 본문 지면 */
  --surface-tint: #F5F7F8;  /* 표지 블록과 절 구분면에만 */
  --brand-tint:   #EAF1F3;  /* 줄무늬 행, 코드 바탕, 콜아웃 */
  --rule:         #CBD5DB;  /* 표 괘선, 구분선 */

  /* 먹 — 순검정을 쓰지 않는다 */
  --ink:       #18222B;  /* 본문 */
  --ink-muted: #4F5D68;  /* 캡션, 부제, 메타 */

  /* 브랜드 */
  --brand:       #17324D;  /* 제목, 표 머리행, 채운 면 */
  --brand-light: #2D6A78;  /* 제목 아래 규칙선, 인용 바, 번호 */
  --brand-deep:  #0B5D7A;  /* 링크, 인라인 코드 */
  --on-brand:    #FFFFFF;  /* 브랜드 면 위의 글자 */

  /* 방향 — 지표의 증감에만 */
  --positive: #147D64;
  --negative: #B8433F;

  /* 계열색 — 색각 이상에서도 구분되도록 검증된 순서다. 순서를 바꾸지 않는다 */
  --c1: #2A78D6; --c2: #EB6834; --c3: #1BAF7A; --c4: #EDA100;
  --c5: #E87BA4; --c6: #4A3AA7; --c7: #E34948; --c8: #898781;
}
```

**쓰는 법**

- **본문 지면은 흰색이다.** 문서 전체에 색을 깔면 인쇄할 때 잉크값이 되고 복사본에는
  얼룩으로 남는다. 색을 공짜로 받는 면(표지 블록, 절 구분면)에만 `--surface-tint`를 쓰고,
  나머지 지면은 제목 아래 `--brand-light` 규칙선 하나로 위계를 만든다.
- **순검정과 순백 글자를 쓰지 않는다.** 본문은 `--ink`, 브랜드 면 위 글자만 `--on-brand`다.
- 브랜드색이 나타나는 자리는 정해져 있다 — 제목, 표 머리행, 표지 규칙선, 링크,
  차트의 주 계열. 넓은 면을 브랜드색으로 칠하지 않는다.
- 증감 색은 지표의 **방향**에만 쓴다. 좋고 나쁨을 뜻하지 않는다. 이탈률 상승은 초록이
  아니다. 방향과 좋음이 어긋나면 색 대신 글자로 적는다.
- **다크 모드를 만들지 않는다.** 같은 리포트가 PDF로도 나가는데 화면에서만 반전되면
  두 개의 다른 문서가 된다. 색과 배치가 정체성을 나르고, 그건 인쇄에서도 살아남아야 한다.

## 2. 활자

**웹폰트를 링크하지 않는다.** 오프라인이나 사내망에서 리포트가 깨지고, 한글을 담지 않은
얼굴을 지정하면 대체 글꼴을 아무도 고르지 않은 채 결정된다. 시스템 스택으로 간다.

```css
:root {
  --font-sans:  system-ui, -apple-system, "Segoe UI", sans-serif;
  --font-serif: Georgia, "Times New Roman", serif;
  --font-mono:  ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;
}
```

`<html lang="ko">`를 반드시 선언한다. 브라우저가 그 언어에 맞는 한글 얼굴을 고르고,
선언이 없으면 읽는 사람의 로캘이 대신 고른다.

| 역할 | 글꼴 | 크기 | 줄 간격 |
|---|---|---|---|
| 머리말(kicker) | sans | 0.75rem | 1.4 · 대문자, 자간 0.12em, `--ink-muted` |
| 제목 | sans | `clamp(2rem, 5vw, 2.5rem)` | 1.15 |
| 부제(dek) | serif | 1.25rem | 1.4 · `--ink-muted` |
| 절 제목 | sans | 1.5rem | 1.2 |
| 소제목 | sans | 1.125rem | 1.3 |
| 본문 | serif | 1.0625rem | 1.5 |
| 캡션·메타 | sans | 0.8125rem | 1.5 · `--ink-muted` |
| 수치 | sans | `clamp(2rem, 4vw, 2.5rem)` | 1.1 · `tabular-nums` |
| 표·코드 | sans·mono | 0.9375rem·0.875rem | 1.35 |

줄 간격은 문서 렌더러가 쓰는 비율과 같다 — 본문 1.5, 제목 1.2, 표지 제목 1.15,
부제 1.4, 표·코드 1.35. 자간은 0으로 둔다. 한글은 정사각 진행이 자연스럽고, 글자를
눌러서 줄을 맞추지 않는다.

산세리프로 구조를, 세리프로 산문을 나른다. 본문에 산세리프를 섞지 않는다.

## 3. 여백과 단

```css
:root {
  --s-1: .25rem; --s-2: .5rem; --s-3: .75rem; --s-4: 1rem;
  --s-5: 1.5rem; --s-6: 2rem; --s-7: 3rem; --s-8: 4rem;

  --measure: 68ch;   /* 산문 단 너비 */
  --wide:    1100px; /* 차트·표가 빠져나오는 너비 */
  --page:    1400px; /* 목차를 포함한 지면 전체 */
}
```

- 산문은 `--measure`를 넘기지 않는다. 한 줄이 65~75자다.
- 차트·표·전면 그림은 `--wide`까지 넓어져도 된다. 나머지는 단 안에 둔다.
- 절 사이는 `--s-8`, 문단 사이는 `--s-4`, 제목과 첫 문단 사이는 `--s-3`.
- 목차는 `1024px` 이상에서만 고정 사이드로 띄우고, 그 아래에서는 문서 앞에 둔다.

## 4. 구성 요소

**제목 블록** — 머리말, 제목, 부제 한 문장, 날짜·작성자 메타. `--surface-tint` 면 위에
놓고 제목 아래에 `--brand-light` 3px 규칙선을 64px 길이로 긋는다. 규칙선이 위계를
표시하고, 같은 장식을 다른 페이지에서 반복하지 않는다.

**목차** — `position: sticky`. 현재 절은 `--brand-deep` 글자색에 왼쪽 2px 선을 준다.
스크롤 추적은 `IntersectionObserver`로 하고, 실패해도 링크는 그냥 동작해야 한다.

**핵심 수치** — 2~4개를 한 줄에 놓는다. 각 칸은 값, 라벨, 비교 한 줄로 이루어진다.
값은 등폭 숫자를 쓰고 단위는 값보다 작게 붙인다. 칸 사이는 `--rule` 세로선으로 나눈다.

**그림(figure)** — 차트나 표를 감싸고 `figcaption`을 아래에 둔다. 캡션에 무엇을 보여주는지와
기간·모집단·출처를 적는다. 캡션 없는 차트를 두지 않는다.

**표** — **가로 괘선만 쓴다.** 세로선은 숫자를 하나씩 가두고, 눈은 표를 행으로 읽는다.
머리행은 `--brand` 채움에 `--on-brand` 글자다. 행 사이는 `--rule` 한 줄, 줄무늬가
필요하면 `--brand-tint`를 홀수 행에 옅게. 숫자 열은 오른쪽 정렬에 등폭 숫자.
행이 스무 개를 넘으면 정렬 기능을 준다.

**콜아웃** — `--brand-tint` 바탕에 왼쪽 `--brand-light` 3px 선. 본문에서 빼도 되는 보충
설명에만 쓰고 한 절에 하나를 넘지 않는다.

**출처와 각주** — 본문에 위 첨자 번호를 링크로 달고, 문서 끝 목록에서 본문으로 돌아오는
링크를 준다.

## 5. 인쇄

```css
@media print {
  nav, .toc, .controls { display: none; }
  body { font-size: 10.5pt; }
  h2, figure, table { break-inside: avoid; }
  a[href^="http"]::after { content: " (" attr(href) ")"; font-size: 8pt; color: #555; }
}
```

본문이 이미 흰 지면이라 인쇄용으로 색을 되돌릴 것이 없다. 링크 주소를 각주처럼 펼쳐
두면 종이로 읽는 사람이 출처를 확인할 수 있다.
