# 리포트 안의 차트

차트는 독자의 비교 질문과 데이터에 맞춰 고른다. 비교에는 막대, 추세에는 선, 분포에는
히스토그램, 관계에는 산점도를 사용할 수 있다. 결측치를 0으로 바꾸지 않고 막대 축은 0에서
시작한다. 상세 설계가 필요하고 `tufte-charts`가 제공될 때만 그 스킬을 읽는다.

## 기본은 인라인 SVG

리포트는 파일 하나로 돌아다닌다. 외부 스크립트를 불러오면 오프라인·사내망·인쇄에서 빈
자리가 남는다. 기본값은 손으로 쓰는 인라인 SVG다. 축·눈금·계열을 직접 그리는 대신 값에서
좌표를 계산해 `<path>`와 `<rect>`로 찍는다.

차트 라이브러리는 이 조건을 모두 만족할 때만 쓴다.

- 필요한 라이브러리 코드를 HTML 안에 포함해 외부 요청 없이 동작한다.
- 상호작용(줌, 브러시, 수십 계열 토글)이 정말 필요하다.
- 로드가 실패해도 표나 텍스트 요약이 대신 보인다.

## 지면과 맞추기

- 계열색은 보고서 토큰을 사용한다. 기본값은 `--c1`~`--c8`이며 브랜드·범주 의미에 맞게
  조정할 수 있다. 색만으로 구분하지 않고 실제 배경 대비와 흑백 표현을 확인한다.
- 계열이 하나면 `--c1`로 그린다. 증감은 부호와 값으로 표시하고 의미가 확인될 때만
  `--positive`·`--negative` 같은 상태색을 붙인다.
- 배경을 칠하지 않는다. 흰 지면이 그대로 보이게 둔다.
- 격자선은 가로만, `--rule` 색으로 1px. 세로 격자선은 시간축 눈금이 필요할 때만.
- 축선은 얇게 하거나 없앤다. 눈금 라벨은 `--ink-muted`, 0.75rem.
- 글자는 지면과 같은 산세리프를 쓴다. SVG 안에서 폰트를 따로 지정하지 않고 상속받는다.
- 반응형은 `viewBox`와 `width: 100%`로 처리한다. 고정 픽셀 크기를 주지 않는다.

## 라벨

- 범례 대신 계열 끝에 직접 라벨을 붙인다. 눈이 범례와 선을 오가지 않아도 된다.
- 값이 중요하면 축 눈금을 줄이고 데이터 점 옆에 숫자를 적는다.
- 축 제목에 단위를 넣는다(`매출 (백만원)`). 값마다 단위를 반복하지 않는다.
- 긴 항목 이름은 막대를 가로로 눕혀서 그대로 읽히게 한다. 라벨을 45도로 기울이지 않는다.

## 접근성

- `<svg role="img">`에 `<title>`을 넣고 `aria-labelledby`로 연결한다. 제목은 차트가
  말하려는 결론으로 쓴다. "월별 추이"가 아니라 "3월 이후 재방문율이 4%p 올랐다".
- 색만으로 계열을 구분하지 않는다. 선 모양이나 직접 라벨을 함께 준다.
- 데이터 크기에 맞는 원본 표나 텍스트 요약을 제공한다. 접힌 표를 사용하면 인쇄에서
  내용이 보이는지도 확인한다. 데이터가 많다는 이유로 텍스트 대안을 생략하지 않는다.

## 하지 않는 것

- 3D, 그림자, 그라데이션 채움
- 도넛 가운데 총합, 원형 차트 여러 개를 나란히 두기
- 0에서 시작하지 않는 막대 축
- 애니메이션으로 올라가는 숫자와 그려지는 선 — 독자는 그동안 값을 읽지 못한다
- 픽셀로 고정한 크기, 화면 폭에서 잘리는 차트
